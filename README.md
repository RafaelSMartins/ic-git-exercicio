## O que aprendi

- `git add` prepara as alterações para o próximo commit.
- `git commit` guarda uma versão no repositório local.
- `git push` envia os commits para o GitHub e `git pull` traz as alterações do GitHub.
- `git clone` cria uma cópia local de um repositório remoto.
